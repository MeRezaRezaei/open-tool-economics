# Welcome to Open Tools, Gated Performance

This repo exists to put an answer into circulation. The answer, in one line:

> **Separate the tool from the performance. Keep tools open; charge only for the doing.**

## Read first

1. **`MANIFESTO.md`** — the answer, why it works, and how to act on it.
2. **`PLEDGE.md`** — the public commitment you can take.
3. **`VERBATIM.md`** — the original statement of the idea.
4. **`framework/`** — the three laws in depth (Separation Law, Layer Principle, Incentive Model).

## Act

- **[Take the Pledge](https://github.com/MeRezaRezaei/open-tool-economics/issues/new?template=pledge.yml)** — open an issue signed by you.
- **[Propose a separation](https://github.com/MeRezaRezaei/open-tool-economics/issues/new?template=separation.yml)** — find a tool hidden inside a performance and share it.
- **Improve the doctrine** — open a PR refining the framework.

## Contributing

The doctrine is open (MIT). Contributions are welcome. As the doctrine itself says: if you depend on these tools, improving them is your own business — a better framework lifts every performance built on it.
