# Open Tools, Gated Performance

**The tools are open. The performance is what we sell.**

---

## The answer in one sentence

Separate the tool from the performance. **Keep tools open to everyone; charge only for the doing.**

## The three laws

1. **The Separation Law** — *remove it and the performance degrades; add it and the performance evolves.* That is how you detect a tool in anything.
2. **The Layer Principle** — the libs that build MySQL are tools to MySQL; MySQL is a tool to developers; the next tool is the schema. Every layer can be opened; nothing can be monopolized.
3. **The Incentive Model** — performance is paid, so performers fund the tools. If they don't, someone else will. Open tools survive because value flows to the doing.
