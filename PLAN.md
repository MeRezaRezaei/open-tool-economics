# Plan — representing the idea, not coding it

The deliverable of this repo is the **idea**, represented clearly enough to be understood, shared, and argued with. No code.

## What the idea is

Separate the **tool** from the **performance**:

- Tools are opened to everyone.
- Performance — the act of using tools to create value — is where money is made.
- This makes monopoly impossible, keeps open tools alive, and moves competition from *owning* to *doing*.

Three components carry it:

1. **The Separation Law** — *remove it → performance degrades; add it → performance evolves*. This is how we detect what is a tool and what is performance in any system.
2. **The Layer Principle** — tools nest inside tools, and every layer can be opened independently.
3. **The Incentive Model** — open tools + paid performance → performers fund the tools, because if they don't, others will.
